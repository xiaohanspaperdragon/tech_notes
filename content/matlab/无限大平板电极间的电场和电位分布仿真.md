### 2. 理论原理
**问题描述**：两无限大平行板电极，间距为 $d$，下板（$x=0$）电位为 $0$，上板（$x=d$）电位为 $V$。板间充满体电荷，密度为 $\rho$（常数）。
**控制方程**：一维泊松方程
$$
\frac{d^2 \Phi}{dx^2} = -\frac{\rho}{\varepsilon}
$$
**边界条件**：
$$
\Phi(0) = 0,\quad \Phi(d) = V
$$
**解析解**：对泊松方程两次积分得：
$$
\Phi(x) = -\frac{\rho}{2\varepsilon}x^2 + C_1 x + C_2
$$
代入边界条件：
$$
\Phi(x) = \frac{V}{d}x - \frac{\rho}{2\varepsilon}x(x-d)
$$
电场强度：
$$
E(x) = -\frac{d\Phi}{dx} = -\frac{V}{d} + \frac{\rho}{\varepsilon}\left(x - \frac{d}{2}\right)
$$
### 3. 模型搭建
使用 MATLAB 求解并绘制电位和电场分布：

```matlab
clear; clc; close all;

%% 参数设置
V = 10;                  % 上板电位 (V)
d = 5;                   % 板间距 (m)
rho = 1e-8;              % 体电荷密度 (C/m³)
eps0 = 8.85e-12;         % 真空介电常数 (F/m)

%% 生成坐标点
x = linspace(0, d, 100);

%% 电位分布公式
phi = (V/d) * x - (rho/(2*eps0)) * x .* (x - d);

%% 电场分布公式
E = -V/d + (rho/eps0) * (x - d/2);

%% ========== 图1：电位随 x 的变化关系 ==========
figure('Position', [100, 100, 800, 300]);

subplot(1,2,1)
plot(x, phi, 'b-', 'LineWidth', 2.5)
hold on
plot(x, phi, 'bo', 'MarkerSize', 4, 'MarkerFaceColor', 'b')
grid on
xlabel('距离 x (m)', 'FontSize', 11)
ylabel('电位 Φ (V)', 'FontSize', 11)
title('电位随 x 的变化关系', 'FontSize', 12, 'FontWeight', 'bold')
legend('电位分布', '电位值', 'Location', 'best')

%% ========== 图2：电场随 x 的变化关系 ==========
subplot(1,2,2)
plot(x, E, 'r-', 'LineWidth', 2.5)
hold on
plot(x, E, 'rs', 'MarkerSize', 4, 'MarkerFaceColor', 'r')
grid on
xlabel('距离 x (m)', 'FontSize', 11)
ylabel('电场强度 E (V/m)', 'FontSize', 11)
title('电场随 x 的变化关系', 'FontSize', 12, 'FontWeight', 'bold')
legend('电场分布', '电场值', 'Location', 'best')

%% ========== 图3：电位等值面分布（修正版） ==========
figure('Position', [100, 100, 800, 400]);

% 构建二维网格
y = linspace(-3, 3, 50);
[X, Y] = meshgrid(x, y);

% 电位仅与 x 有关，与 y 无关
Phi_grid = (V/d) * X - (rho/(2*eps0)) * X .* (X - d);

% 绘制等值线图
contourf(X, Y, Phi_grid, 20, 'LineWidth', 0.5)
colorbar
colormap(jet)
xlabel('x (m)', 'FontSize', 12)
ylabel('y (m)', 'FontSize', 12)
title('无限大平板电极间电位等值面分布', 'FontSize', 14)
axis equal

% 标注电极位置
hold on
line([0, 0], [-3, 3], 'Color', 'k', 'LineWidth', 2, 'LineStyle', '-')
line([d, d], [-3, 3], 'Color', 'k', 'LineWidth', 2, 'LineStyle', '-')
text(0, 3.2, '下板 Φ=0', 'FontSize', 10, 'HorizontalAlignment', 'center')
text(d, 3.2, '上板 Φ=V', 'FontSize', 10, 'HorizontalAlignment', 'center')

%% ========== 图4：电场矢量与等位线（修正版） ==========
figure('Position', [100, 100, 800, 400]);

% 构建电场矢量场（需要与网格尺寸匹配）
% E 是沿 x 方向的标量场，需要扩展到网格大小
E_grid = -V/d + (rho/eps0) * (X - d/2);  % 电场大小（与 X 同尺寸）
Ex_grid = -E_grid;    % 电场方向沿 x 轴（负梯度方向）
Ey_grid = zeros(size(E_grid));  % y 方向分量为 0

% 为清晰显示，对网格进行降采样（避免箭头过于密集）
step = 4;  % 每隔4个点显示一个箭头
X_quiver = X(1:step:end, 1:step:end);
Y_quiver = Y(1:step:end, 1:step:end);
Ex_quiver = Ex_grid(1:step:end, 1:step:end);
Ey_quiver = Ey_grid(1:step:end, 1:step:end);

% 绘制电场矢量箭头
quiver(X_quiver, Y_quiver, Ex_quiver, Ey_quiver, 1.5, 'b', 'LineWidth', 1)
hold on

% 添加等位线作为背景
contour(X, Y, Phi_grid, 15, 'k--', 'LineWidth', 0.8)

xlabel('x (m)', 'FontSize', 12)
ylabel('y (m)', 'FontSize', 12)
title('电场矢量分布（箭头）与等位线（虚线）', 'FontSize', 14)
axis equal

% 标注电极位置
line([0, 0], [-3, 3], 'Color', 'k', 'LineWidth', 2)
line([d, d], [-3, 3], 'Color', 'k', 'LineWidth', 2)
text(0, 3.2, '下板 Φ=0', 'FontSize', 10, 'HorizontalAlignment', 'center')
text(d, 3.2, '上板 Φ=V', 'FontSize', 10, 'HorizontalAlignment', 'center')

%% ========== 图5：三维电位分布曲面 ==========
figure('Position', [100, 100, 900, 500]);

% 绘制三维曲面
surf(X, Y, Phi_grid, 'EdgeColor', 'none')
colormap(jet)
colorbar
xlabel('x (m)', 'FontSize', 12)
ylabel('y (m)', 'FontSize', 12)
zlabel('电位 Φ (V)', 'FontSize', 12)
title('无限大平板电极间三维电位分布', 'FontSize', 14)
view(45, 30)  % 设置视角
```

### 结果分析
> [!info] 物理规律验证
**情况一：无体电荷（$\rho = 0$）**

| 物理量 | 理论表达式 | 分布特点 |
|:------:|:----------:|:--------:|
| 电位 | $\Phi(x) = \dfrac{V}{d}x$ | **线性分布** |
| 电场 | $E = -\dfrac{V}{d}$ | **均匀常量** |

**情况二：有体电荷（$\rho \neq 0$）**

| 物理量 | 理论表达式 | 分布特点 |
|:------:|:----------:|:--------:|
| 电位 | $\Phi(x) = \dfrac{V}{d}x - \dfrac{\rho}{2\varepsilon}x(x-d)$ | **二次抛物线** |
| 电场 | $E = -\dfrac{V}{d} + \dfrac{\rho}{\varepsilon}\left(x - \dfrac{d}{2}\right)$ | **线性分布** |

> [!warning] 关键观察
> - 体电荷 $\rho > 0$ 时，电位曲线**向下弯曲**（二次项系数为负）
> - 体电荷 $\rho < 0$ 时，电位曲线**向上弯曲**
> - 电场强度在中点 $x = d/2$ 处等于 $-V/d$，与 $\rho$ 无关
> - 等位面为平面簇，电场线垂直于极板

## 五、实验结论

> [!success] 实验收获
> 1. **掌握一维泊松方程求解**：$\dfrac{d^2\Phi}{dx^2} = -\rho/\varepsilon$
> 2. **理解分布规律**：
>    - $\rho = 0$：电位**线性**，电场**均匀**
>    - $\rho \neq 0$：电位**抛物线**，电场**线性**
> 3. **掌握 MATLAB 可视化**：
>    - 电位随 $x$ 变化曲线
>    - 电位等值面（二维等位线）
>    - 电场矢量分布图
> 4. **数值与解析结合**：解析解验证数值结果

> [!summary] 核心结论
> - **电位分布**：$\Phi(x) = \dfrac{V}{d}x - \dfrac{\rho}{2\varepsilon}x(x-d)$
> - **电场分布**：$E(x) = -\dfrac{V}{d} + \dfrac{\rho}{\varepsilon}\left(x - \dfrac{d}{2}\right)$
> - 体电荷密度 $\rho$ 使电位分布从线性变为**二次曲线**
> - 等位面为**平面簇**，电场线**垂直于极板**
> - MATLAB 仿真结果与理论解析解**高度吻合**
