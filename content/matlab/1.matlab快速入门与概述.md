### 例19
已知某个传感器的传递函数为：
$$
H_s(s) = -K_s \frac{s\omega_n^2}{s^2 + 2\xi\omega_n s + \omega_n^2}
$$

式中 $\omega_n^2$、$K_s$、$\xi$ 分别为：

$$
\omega_n^2 = \frac{R_0 + R_s}{L_0 C_0 R_s}, \quad 
K_s = \frac{M R_s}{R_s + R_0}, \quad 
\xi = \frac{R_s + R_0 + L_0}{2\sqrt{R_s + R_0}\sqrt{R_s L_0 C_0}}
$$

需要研究该传感器的以下特性：  
(1) 单位阶跃响应；  
(2) 幅频特性和相频特性。

假设式（1-1）中各个参数的取值分别为：

$$
R_0 = 0.5\Omega, \quad M = 100\mu H, \quad R_s = 0.05\Omega, \quad L_0 = nM, \quad n = 50, \quad C_0 = 100pF
$$

现用 MATLAB 的编辑器创建 M 文件，并保存为 `exm_20_Step.m`：

```matlab
% 研究传感器的单位阶跃响应
% 参数赋值

R0 = 0.5; 
M = 100e-6; 
Rs = 0.05; 
n = 50; 
L0 = n * M; 
C0 = 100e-12; 
k = -M * Rs / (R0 + Rs);

pusine = (L0 + R0) / 2 / sqrt(Rs * L0 * C0 * (Rs + R0));
womga = sqrt((Rs + R0) / (Rs * L0 * C0));

% 定义传感器的传递函数的分子与分母
num = [k * womga * womga, 0];
den = [1, 2 * womga * pusine, womga * womga];

sys = step(num, den);

plot(sys, 'r', 'linewidth', 3), grid on;

% 获取传感器传递函数的单位阶跃响应曲线，并添加网格线
title('传感器的单位阶跃响应');
xlabel('Second');
```

执行本程序，即可获得传感器的单位阶跃响应曲线，如图所示

### 例27
#### 整流波形描述方法举例
**【举例27】** 逐段解析函数的计算和表达。如果要绘制图1-47所示图形，可以在MATLAB的编辑器窗口中键入以下命令并保存为 `exm_28.m`：

```matlab
% 逐段解析函数的计算和表达

t = linspace(0, 3*pi, 500); % 从0到3*pi均匀产生500个数据，赋值给t

y = 10 * sin(t); % 产生正弦波

z = (y >= 0) .* y; % 正弦波叠加半波（正半波保留，负半波置零）

a = 10 * sin(pi/3); % 设定阈值

z = (y >= a) * a + (y < a) .* z; % 前项的正弦波叠加半波（幅值限制）

plot(t, y, 'r--', 'linewidth', 3); hold on; % 红色虚线

plot(t, z, 'b', 'linewidth', 3); % 蓝色实线

% 绘图形添加横、纵坐标和标题

xlabel('时间 t');

ylabel('幅值');

title('逐段解析函数示例');

legend('y = 10sin(t)', '整流后波形');

grid on;
```

已知某电路中，如图所示，电阻 \( R = 10\Omega \)，电流 \( I \) 分别由 \( 0A \sim 10A \)，其步长为 \( 0.5A \)，试用 MATLAB 编制该电阻端电压 \( U \) 和它消耗功率 \( P \) 的程序，并绘制 \( I-U \)、\( I-P \) 曲线。

```matlab
clear, clc, close        % 清空工作区变量、清空命令窗口、关闭所有图形窗口

R = 10;                  % 电阻值设为 10Ω
i = (0:0.5:10);          % 电流从 0A 到 10A，步长 0.5A
v = i .* R;              % 根据欧姆定律 U = I * R 计算端电压
p = (i .^ 2) .* R;       % 根据功率公式 P = I^2 * R 计算消耗功率
sol = [i v p]            % 在命令窗口显示电流、电压、功率的数值表（三列）

subplot(2, 1, 1)         % 分割图形窗口为 2 行 1 列，选中第 1 个子图（上）
plot(i, v, 'r', 'linewidth', 3)   % 绘制 I-U 曲线，红色实线，线宽 3
title('端电压值 U/V')     % 添加子图标题
xlabel('I/A')            % 添加横坐标标签
grid on                  % 添加网格线

subplot(2, 1, 2)         % 分割图形窗口为 2 行 1 列，选中第 2 个子图（下）
plot(i, p, 'b', 'linewidth', 3)   % 绘制 I-P 曲线，蓝色实线，线宽 3
title('功率值 P/W')       % 添加子图标题
xlabel('I/A')            % 添加横坐标标签
grid on                  % 添加网格线
```

### 练5
已知某脉冲电容器的端电压的表达式为：

$$
u(t) = 10(1 - e^{-0.2t})
$$

试给出时间 $t = 0 \sim 50s$，步长为 1s 的电压值。

```matlab
clear; clc; close;          % 清空工作区、清空命令窗口、关闭所有图形窗口

% 产生时间值，从 0 到 50s，步长为 1s
t = (0:1:50)';              % 生成 51×1 的列向量

% 计算端电压值 u(t) = 10(1 - e^(-0.2t))
u = 10 * (1 - exp(-0.2 * t));

% 分别显示时间和电压值（数值表）
sol = [t, u]                % 在命令窗口显示两列：时间 t 和电压 u

% 绘制电压随时间变化的曲线
plot(t, u, 'r', 'linewidth', 3);   % 红色实线，线宽 3
title('端电压值 u(V)');            % 添加标题
xlabel('t(s)');                    % 添加横坐标标签
ylabel('u(V)');                    % 添加纵坐标标签
grid on;                           % 添加网格线
```
