### 2. 理论原理

根据安培环路定理，无限长直导线产生的磁感应强度为：

$$
B = \frac{\mu_0 I}{2\pi r}
$$

其中：
- $\mu_0 = 4\pi \times 10^{-7} \, \text{H/m}$，真空磁导率
- $I$：导线中的电流强度（A）
- $r$：到导线的垂直距离（m）

**磁场方向**：由右手螺旋定则确定，磁感应线为环绕导线的同心圆。

### 3. 模型搭建

```matlab
clear; clc; close all

% 参数设置
mu0 = 4*pi*1e-7;    % 真空磁导率
I = 1;              % 电流强度 (A)
r_max = 2;          % 最大距离 (m)
r_min = 0.1;        % 最小距离，避免奇点

% 计算磁感应强度随距离变化
r = linspace(r_min, r_max, 100);
B = mu0 * I ./ (2 * pi * r);

% 绘制 B-r 曲线
figure
plot(r, B, 'b-', 'LineWidth', 2)
grid on
xlabel('距离 r (m)', 'FontSize', 12)
ylabel('磁感应强度 B (T)', 'FontSize', 12)
title('无限长直导线 B 随距离变化曲线', 'FontSize', 14)

% 绘制磁感应线（同心圆）
figure
hold on
axis equal
grid on

% 绘制不同半径的同心圆
radii = 0.2:0.2:1.8;
for R = radii
    theta = linspace(0, 2*pi, 100);
    x = R * cos(theta);
    y = R * sin(theta);
    plot(x, y, 'r-', 'LineWidth', 1.5)
end

% 绘制导线（中心点）
plot(0, 0, 'ko', 'MarkerSize', 10, 'MarkerFaceColor', 'k')

% 标注电流方向（向上，用 ⊙ 表示流出）
text(0, 0.1, '⊙', 'FontSize', 16, 'HorizontalAlignment', 'center')

xlabel('x (m)', 'FontSize', 12)
ylabel('y (m)', 'FontSize', 12)
title('无限长直导线磁感应线分布', 'FontSize', 14)
legend('磁感应线', '载流导线')

% 添加方向箭头（表示磁场方向，逆时针）
for R = [0.5, 1.0, 1.5]
    % 在圆上添加方向箭头
    for theta = [30, 90, 150, 210, 270, 330]
        theta_rad = theta * pi/180;
        x0 = R * cos(theta_rad);
        y0 = R * sin(theta_rad);
        
        % 切线方向（逆时针）
        dx = -sin(theta_rad);
        dy = cos(theta_rad);
        
        % 归一化并缩放
        dx = dx * 0.15;
        dy = dy * 0.15;
        
        quiver(x0, y0, dx, dy, 0, 'b', 'LineWidth', 1, 'MaxHeadSize', 0.5)
    end
end

% 添加标注
text(-1.8, -1.6, '磁场方向：逆时针', 'FontSize', 10, 'Color', 'b')
text(-1.8, -1.9, '右手定则：拇指向上（电流方向）', 'FontSize', 10)
text(-1.8, -2.2, '四指弯曲方向即磁场方向', 'FontSize', 10)
```
