### **TCON（Timer/Counter Control Register）** 定时控制寄存器各位英文全称及含义：

| 位名称 | 英文全称 | 中文含义 |
|--------|---------|----------|
| **TF1** | **Timer 1 Overflow Flag** | 定时器1溢出标志 |
| **TR1** | **Timer 1 Run Control** | 定时器1运行控制 |
| **TF0** | **Timer 0 Overflow Flag** | 定时器0溢出标志 |
| **TR0** | **Timer 0 Run Control** | 定时器0运行控制 |
| **IE1** | **Interrupt 1 Edge Flag** | 外部中断1触发标志 |
| **IT1** | **Interrupt 1 Trigger Mode** | 外部中断1触发方式选择 |
| **IE0** | **Interrupt 0 Edge Flag** | 外部中断0触发标志 |
| **IT0** | **Interrupt 0 Trigger Mode** | 外部中断0触发方式选择 |

### **IE（Interrupt Enable）中断允许控制寄存器**各位的英文全称及含义：

| 位序 | 位地址 | 位名称 | 英文全称 | 中文含义 |
|------|--------|--------|---------|----------|
| 位7 | AFH | **EA** | **Enable All** | 总中断允许位 |
| 位6 | AEH | — | (Reserved) | 保留位（未用） |
| 位5 | ADH | — | (Reserved) | 保留位（未用） |
| 位4 | ACH | **ES** | **Enable Serial** | 串行口中断允许位 |
| 位3 | ABH | **ET1** | **Enable Timer 1** | 定时器1中断允许位 |
| 位2 | AAH | **EX1** | **Enable External 1** | 外部中断1允许位 |
| 位1 | A9H | **ET0** | **Enable Timer 0** | 定时器0中断允许位 |
| 位0 | A8H | **EX0** | **Enable External 0** | 外部中断0允许位 |

### **IP（Interrupt Priority）中断优先级控制寄存器** 
**IP = Interrupt Priority Register**（中断优先级控制寄存器）

| 位序 | 位地址 | 位名称 | 英文全称 | 中文含义 |
|------|--------|--------|---------|----------|
| 位7 | BFH | — | (Reserved) | 保留位（未用） |
| 位6 | BEH | — | (Reserved) | 保留位（未用） |
| 位5 | BDH | — | (Reserved) | 保留位（未用） |
| 位4 | BCH | **PS** | **Priority Serial** | 串行口中断优先级控制 |
| 位3 | BBH | **PT1** | **Priority Timer 1** | 定时器1中断优先级控制 |
| 位2 | BAH | **PX1** | **Priority External 1** | 外部中断1优先级控制 |
| 位1 | B9H | **PT0** | **Priority Timer 0** | 定时器0中断优先级控制 |
| 位0 | B8H | **PX0** | **Priority External 0** | 外部中断0优先级控制 |

### **TMOD = Timer/Counter Mode Register**（定时器/计数器模式控制寄存器）

| 位序 | 位名称 | 英文全称 | 中文含义 |
|------|--------|---------|----------|
| 位7 | **GATE1** | **Gate Control 1** | 定时器1门控位 |
| 位6 | **C/T1** | **Counter/Timer 1** | 定时器1计数/定时模式选择 |
| 位5 | **M11** | **Mode 1 bit 1** | 定时器1模式选择位1 |
| 位4 | **M10** | **Mode 1 bit 0** | 定时器1模式选择位0 |
| 位3 | **GATE0** | **Gate Control 0** | 定时器0门控位 |
| 位2 | **C/T0** | **Counter/Timer 0** | 定时器0计数/定时模式选择 |
| 位1 | **M01** | **Mode 0 bit 1** | 定时器0模式选择位1 |
| 位0 | **M00** | **Mode 0 bit 0** | 定时器0模式选择位0 |

### `interrupt` —— 最核心的关键字

 基本语法
```c
void 函数名() interrupt 中断号
{
    // 中断服务代码
}
```

 中断号对照表

| 中断源    | 中断号   | 中断向量地址 |
| ------ | ----- | ------ |
| 外部中断 0 | **0** | 0003H  |
| 定时器 0  | **1** | 000BH  |
| 外部中断 1 | **2** | 0013H  |
| 定时器 1  | **3** | 001BH  |
| 串行口    | **4** | 0023H  |

### **SCON** 是 **Serial Port Control Register**（串行口控制寄存器）的缩写，用于设定串行口的工作方式、接收/发送控制以及状态标志。

其各位英文全称及功能如下表所示（地址为 `0x98`，可位寻址）：

| 位序 | 位地址 | 位符号 | 英文全称 | 中文含义 |
| :--- | :--- | :--- | :--- | :--- |
| **位 7** | `9FH` | **SM0** | **Serial Port Mode Select bit 0** | 串行口工作方式选择位 0 |
| **位 6** | `9EH` | **SM1** | **Serial Port Mode Select bit 1** | 串行口工作方式选择位 1 |
| **位 5** | `9DH` | **SM2** | **Serial Port Mode Select bit 2 / Multiprocessor Communication Enable** | 多机通信控制位 / 方式选择位 2 |
| **位 4** | `9CH` | **REN** | **Receiver Enable** | 接收允许控制位 |
| **位 3** | `9BH` | **TB8** | **Transmitter Bit 8** | 发送数据的第 9 位（方式 2/3 中） |
| **位 2** | `9AH` | **RB8** | **Receiver Bit 8** | 接收数据的第 9 位（方式 2/3 中） |
| **位 1** | `99H` | **TI** | **Transmit Interrupt Flag** | 发送中断标志 |
| **位 0** | `98H` | **RI** | **Receive Interrupt Flag** | 接收中断标志 |
