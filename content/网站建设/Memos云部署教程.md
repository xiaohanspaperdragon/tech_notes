## 购买服务器并创建docker容器镜像
笔者购买的是腾讯的轻量应用服务器，26年暑假买的，月付三四十块，比之前阿里云的月付99要轻松很多。

![[Pasted image 20260903205852.webp]]

1. **镜像选择**：若截图和笔者一样 **UbuntuServer24.04LTS**，就选这个Docker 版本 29.6.1 的吧
    
2. **添加容器**：点击 **“+添加容器”** 按钮，在弹出的表单里填入：
    
    - **容器名称**：输入 `memos`（自定义即可）。
        
    - **镜像**：输入 `neosmemo/memos:stable`（这是官方镜像地址）。
        
    - **端口映射**：
        
        - 容器端口填：xxxx
            
        - 主机端口也填：xxxx（这是你访问服务器的端口）
            
    - **挂载卷（数据持久化）**：
        
        - 容器路径填：`/var/opt/memos`
            
        - 主机路径填：`/data/memos`（或自定义任意路径，用于存放数据）
            
3. **直接购买**：填好后点购买，服务器启动后，Memos 就已经在里面跑起来了，直接访问 `http://你的服务器IP:xxxx` 即可。

## 配置容器(可选)

![[Pasted image 20260903210154.webp]]

### 1. 容器名称

- **填什么**：`memos`
    
- **为什么**：就是个名字，方便你辨认。
    
### 2. Docker镜像

- **填什么**：`neosmemo/memos:stable`
    
- **为什么**：这是Memos官方镜像地址。`stable`表示稳定版。
    
### 3. 启动命令

- **填什么**：**什么都不填，空着**
    
- **为什么**：Memos镜像自带默认启动命令，不需要额外指定。
    
### 4. 绑定端口（关键）

点击 **"+添加端口"**，然后填两行：

| 字段       | 填什么    |
| -------- | ------ |
| **容器端口** | `xxxx` |
| **主机端口** | `xxxx` |

- **为什么**：容器内Memos跑在xxxx端口，映射到服务器的xxxx端口，这样你访问 `http://你的IP:xxxx` 才能看到界面。
    
### 5. 环境变量

- **填什么**：**先空着，不需要填**
    
- **为什么**：Memos可以不配置环境变量直接跑。
    
### 6. 挂载存储卷（关键，防止数据丢失）

点击 **"+添加存储卷"**，填两行：

|字段|填什么|
|---|---|
|**容器路径**|`/var/opt/memos`|
|**主机路径**|`/data/memos`|

- **为什么**：Memos的数据存在容器内的`/var/opt/memos`。如果主机路径不挂载，容器删除后数据就没了。挂载到`/data/memos`后，数据会永久保留在服务器硬盘上。
    
### 7. 器重启策略

- **选什么**：选 **"总是重启容器"**（如果列表里有的话）或 **"不重启容器"**
    
- **为什么**：如果选"总是重启"，服务器重启后Memos会自动启动。但如果列表里没有这个选项，选"不重启"也行，等服务器创建完，你后面再用命令改成自动重启也可以。

## 手动创建容器

### 入门

在本地运行备忘录,创建第一个管理员用户,并发布您的第一份备忘录。

备忘录设计为可在几分钟内使用。最短路径是使用 SQLite 和本地数据卷的 Docker,然后您可以在实例启动后加强部署和存储。

### 先决条件

- Docker 安装在运行 Memos 的机器上

### 启动本地实例

```
docker run -d \
  --name memos \
  -p 5230:5230 \
  -v ~/.memos:/var/opt/memos \
  neosmemo/memos:stable
```

这给你带来了什么:

- `5230` 暴露在主机上
- 持久数据目录位于 `~/.memos`
- 默认情况下为 SQLite
- 一个易于检查和更换的容器

因为命令没有设置 `MEMOS_INSTANCE_URL`, 备忘录以私人模式开始:匿名访问者被发送到登录,并且 Explore 和 RSS 等公共发现表面保持不可用。对于本地或个人实例来说,这是一个安全的默认值。

如果您想要一个已签入的部署文件,请使用 [Docker Compose](https://usememos.com/docs/deploy/docker-compose). 如果您需要自定义或固定构建,请使用 [从源代码构建](https://usememos.com/docs/deploy/development). 贡献者应该从开始 [发展](https://usememos.com/docs/development).

### 验证实例

容器启动后打开UI:

- Docker 默认: `http://localhost:5230`
- 二进制默认值: `http://localhost:8081`

如果您想先从终端验证服务:

```
docker logs memos
```

###  创建第一个管理员帐户

第一个用户成为主机管理员,可以配置注册、身份验证、存储和其他全局设置。

建议的优先行动:

- 使用强密码
- 决定是否保留私有模式或设置规范实例 URL 以启用匿名公共访问
- 决定用户注册是否应保持禁用状态或稍后打开
- 决定是否应允许公开备忘录
